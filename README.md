## 🛠️ Installation Instructions

### 🪟 Windows (10 / 11)
1. Download `MasterJournal-Setup.exe`.
2. Double-click the installer and follow the setup wizard.
3. Launch **Master Journal** directly from your Desktop or Start Menu.

### 🐧 Linux (Debian, Ubuntu, Linux Mint)
* **GUI Method:** Download `MasterJournal-amd64.deb`, double-click the file, and click **"Install Package"**.
* **Terminal Method:**
  ```bash
  sudo dpkg -i MasterJournal-amd64.deb
  ```
* Launch **Master Journal** from your application menu.

## 🛡️ Security & Integrity

* **Zero-Trust Sovereign Privacy:** Your data never touches third-party analytics servers. All trading logs, notes, and metrics remain on your local disk (`0700` restricted permissions).
* **Automatic Hash Verification:** Built-in auto-updater verifies SHA-256 package checksums before running updates.
* **Hardened Storage:** SQLite WAL engine with restricted database read/write permissions (`0600`).
